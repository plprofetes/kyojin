# Sprint 1: risk spikes (fail fast)

[previous sprint](../s0-assess-and-tooling/README.md) · [next sprint](../s2-extension-builds/README.md) · [all sprints](../../README.md) · [deferred](../../deferred.md)

**Goal.** Find out within the first sessions whether serving on Windows is viable. Tasks are ordered hardest and most uncertain first; S1-01 comes first only because every other task needs the toolchain.

**Exit criteria.**
- `doctor` has no FAIL on the target machine and `setup` has completed.
- A minimal HIP extension compiled by `hipcc.exe` (+ `cl.exe` for host code) loads and runs a kernel.
- A real Triton kernel runs correctly on gfx1151 via triton-windows.
- Windows GPU-addressable memory is measured and recorded.
- A small model pack is on disk.

**Gate:** if S1-02 or S1-03 cannot be made to work, stop and re-plan with the user before starting Sprint 2.
